# Python Learning Journey

## Lesson 01: Variables and Conditions

### Objective
Learn how to use variables and if/else
conditions in Python.

### Project
Check the status of a network device.

### Concepts Learned
- Variables
- Strings
- print()
- if and else
- Comparison operator ==

### Example
The program stores:
- Device name: R1
- IP address: 192.168.1.1
- Status: up

It then checks whether the device is up
and prints the appropriate message.
